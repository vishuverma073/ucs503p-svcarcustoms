# Journals

The project ran for **8 weekly iterations (2 months)**. Each member owned one
area and logged one ticket per week: the error, the context, the key
observation and the fix.

## Weekly work plan

| Week | Team focus | Vishu Verma | Raghu Verma | Pratham Sharma | Tarush Mohindru |
|------|-------|-------------|-------------|----------------|-----------------|
| W1 | Requirements and project setup | PayU integration; deployment setup (Vercel, Fly.io, Supabase) | Email-OTP login (switched from SMS) | Storefront header and theme | SRS draft; security review of structured data |
| W2 | Catalogue and admin panel | Fixed the storefront deployment pipeline | Multi-category catalogue (junction table) | Admin product editor on mobile | Server-rendered pages for search engines |
| W3 | Login and accounts | Order confirmation page after payment | Vehicle fitment schema and API | Shop mega-menu | Duplicate product URLs |
| W4 | Vehicle fitment and navigation | COD advance amount in the API | Category caching and invalidation | Category menu and subcategory chips | Google Merchant Center feed |
| W5 | Payments and COD | COD amounts in the checkout UI | Rate limiting for OTP and login | Product detail page | Dependency security upgrade |
| W6 | SEO, images and performance | Payment amount checks on return and webhook | Session cookies via same-origin proxy | Image loading through Supabase | Price-check testing |
| W7 | Security and guest checkout | Payment audit (retry safety) | Security hardening (OTP attempts) | Guest checkout form | CI workflows |
| W8 | Testing, fixes and launch | Launch support (database outage) | Admin product API (SKU sync) | Mobile fixes and design refresh | Canonical URL test; final reports and docs |
