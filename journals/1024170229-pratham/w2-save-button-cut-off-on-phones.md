# Week 2 : Save button cut off on phones

**Team focus this week:** Catalogue and admin panel  
**Work this week:** Admin product editor on mobile

## Error

In the admin product editor on a phone, the Save button was off-screen.

## Relevant Context

Four action buttons with large padding in one row.

## Key Observation

The row was wider than a phone screen.

## Solution

Reordered to Delete · Cancel · Save · Archive with smaller padding so all four fit.

**Because** primary actions must stay visible at the smallest screen width.
